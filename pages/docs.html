quick start

check the harness once, then review. every run freezes an explicit git target and prints one report you can paste into a PR. 

slopguard doctor --engine codex
slopguard review --mode branch --base origin/main --engine codex --prompt "review this change."

review prints a terminal report. pass --output json to get the versioned result-v1 contract on stdout instead.

modes

slopguard review --mode commit --commit HEAD --engine codex --prompt "review this change."

local reviews dirty changes. branch reviews merge-base to HEAD; commit reviews one non-merge commit.

exit codes

0 is a clean review, 1 is findings, 2 is no trustworthy result. slopguard never edits source, runs tests, or falls back to another model.

install

brew install --cask uinaf/tap/slopguard

one binary. the skill ships alongside it in uinaf/ffss.
