shipping a daemon nobody notices

jul 28, 2026 · 4 mins read

the best infra software is invisible until it isn't. healthd's job is to be boring for months and then, one tuesday at 3am, be the most important process on the box.

that shapes every decision: one binary, no runtime deps, config that survives being hand-edited over ssh at 3am.

the 3am test

every feature gets the same question — can a tired person use this over a bad connection? if the answer involves a browser, the feature is wrong.

$ healthd status
gateway   live   41ms
queue     warn   220ms  ← this line pays the rent

we don't guarantee perfection. software has edge cases.
