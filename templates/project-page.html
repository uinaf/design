what it does
  • detects active Codex, Claude, and Cursor desktop or CLI sessions.
  • unions automatic activity with bounded manual wake holds.
  • keeps display sleep optional and releases holds at the battery cutoff.
  • reads process evidence, never prompts, transcripts, files, or network traffic.

$brew install --cask uinaf/tap/slopwake
