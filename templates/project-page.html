healthd · v0.5.1 · mit

the daemon that tells you before your users do.

pluggable host health check daemon in Go. one static binary, no agent mesh, no dashboard subscription. it runs, it watches, it tells you.

installsource ↗
binary size4.1mbstatic, no deps
probes22disk to dns
memory9mbresident, idle
install 
$ brew install uinaf/tap/healthd
$ healthd init && healthd run

works on macOS and linux. windows when someone sends a PR.
