quick start

authorize once, then put files. every upload returns a public preview URL you can paste into a PR. 

attach login
attach put ./shot.png --repo owner/repo --pr 12

put prints a /p/… preview URL. pass --markdown to get an embeddable raw /o/… link instead.

deleting

attach delete <url-or-key>

deletion is immediate. objects expire on their own after 30 days regardless.

auth

upload auth is att_ keys only — never github tokens. agents enroll through the github app; humans use the device flow.
