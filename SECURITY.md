# Security

Do not open public issues for vulnerabilities.

Report privately via GitHub's private vulnerability reporting on this
repository (Security tab → "Report a vulnerability"). Include the affected
surface, a minimal reproduction, and the impact you see.

Scope notes: this package ships CSS tokens and docs only. Berkeley Mono font
binaries must never appear in the published tarball; report any redistribution
of licensed font files through this repository or `@uinaf/design`.
